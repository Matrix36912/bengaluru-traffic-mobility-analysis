# Bengaluru Traffic Mobility Analysis

**Independent Research Project**

A data-driven mobility study evaluating how reducing single-occupancy private car trips can improve congestion, travel efficiency, and transport emissions in Bengaluru.

## Overview

This project combines traffic analytics, forecasting, elasticity modeling, and international benchmarking to examine Bengaluru's long-term mobility challenges.

The analysis compares Bengaluru with **Zurich, Singapore, and Amsterdam** to identify practical mobility strategies that improve transport efficiency rather than relying solely on cleaner vehicles.

## Research Highlights

* Historical traffic analysis (2020–2025)
* Congestion forecasting (2026–2030)
* Elasticity analysis of private car trips
* Trip reduction scenario modeling
* CO₂ emissions estimation
* International benchmarking with Zurich, Singapore, and Amsterdam

## Technologies Used
